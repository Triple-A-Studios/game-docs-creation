# game-docs-creation

Claude Code plugin marketplace for the `game-docs-creation` skill. It manages the full project-documentation and phase/milestone/pass workflow for Unity and Unreal game projects — creating and maintaining `Docs/design-doc.md`, `plan.md`, `progress.md`, `current-state.md`, and a system-organized `technical-design-doc.md`, keeping a managed section of `CLAUDE.md` current so every fresh session knows what to read, and enforcing git hygiene (one branch per milestone, manual verification before any commit, caveman-style commit messages).

## Install

```
/plugin marketplace add Triple-A-Studios/game-docs-creation
/plugin install game-docs-creation@triple-a-studios
```
